# Google Keep Clone

This project is a simple Google Keep style note app built with plain HTML, CSS, and JavaScript.

## Features

- Add notes with title and text
- Pick different note colors
- Search notes
- Archive notes
- Restore archived notes
- Delete notes
- Edit notes in a modal window
- Save notes in browser local storage

## How to run

1. Open the project folder.
2. Start a simple local web server:

   ```bash
   python -m http.server 8000
   ```

3. Open your browser and go to:

   ```text
   http://localhost:8000
   ```

You can also open the `index.html` file directly in a browser, but using a local server is recommended.

## Project files

- `index.html` - main app layout
- `style.css` - styling and layout
- `script.js` - note logic and UI behavior

## Notes

This project is intentionally simple and beginner-friendly, but it still works like a basic Google Keep clone.
